# Enclosure

3D-printable enclosure for the FireFish board. Modeled in **Blender 4.0.2**.

## Files (present)

| File | Variant | Notes |
|---|---|---|
| `firefish_enclosure_short.stl` | short, detailed | Most detailed version (Nov 2024) |
| `firefish_enclosure_short_simple.stl` | short, simplified | Simplified geometry |
| `firefish_enclosure_long_simple.stl` | long, simplified | Longer body variant |

All are binary STL. Prints mate with a standard 2″ underwater housing.
